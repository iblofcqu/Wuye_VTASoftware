# Spec Delta

## ADDED Requirements

### Requirement: 报告生成超时

系统必须（MUST）对质量评估的报告生成阶段实施默认 300 秒的超时控制，并在超时后主动终止对应执行资源。超时范围必须覆盖报告图片渲染、Plotly/Kaleido 直方图导出和 LaTeX/PDF 编译，但不得把上游点云读取、配准或偏差计算本身纳入该超时。超时时间必须可通过配置覆盖。

#### Scenario: 报告在超时前完成

- **GIVEN** 质量评估已完成上游计算并进入报告生成阶段
- **WHEN** PyVista、Kaleido 和 LaTeX 在 300 秒内完成
- **THEN** 任务成功并登记 PDF 报告产物

#### Scenario: 报告阶段超时

- **GIVEN** 报告生成阶段已经开始且超过配置的超时时间仍未完成
- **WHEN** 超时触发
- **THEN** 任务必须变为失败状态，不得登记 PDF 报告产物，并不再无限等待底层进程

#### Scenario: 超时提示最后环节

- **GIVEN** 报告生成的不同子阶段可能发生阻塞
- **WHEN** 超时触发
- **THEN** 失败原因必须包含超时秒数和最后进入的报告子阶段标识，例如报告截图、直方图导出或 PDF 编译

#### Scenario: 超时后释放执行资源

- **GIVEN** 一个报告任务因超时被终止
- **WHEN** 同一计算池中还有其他排队任务
- **THEN** 超时任务占用的 worker 必须被释放，后续任务可以继续执行

#### Scenario: Linux 与 Windows 清理一致性

- **GIVEN** 报告生成因超时被终止
- **WHEN** 系统运行在 Linux 或 Windows
- **THEN** 任务状态、无产物结果和阶段化错误信息必须一致，并且不得留下会阻止后续任务的报告子进程
