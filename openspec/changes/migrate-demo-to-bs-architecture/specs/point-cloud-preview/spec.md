# Spec Delta

## Purpose

定义点云预览的行为：系统在服务端对点云做轻量化后交浏览器展示，用户可旋转、缩放、平移查看单点云、双点云与偏差色带，预览不得影响计算结果。

## ADDED Requirements

### Requirement: 轻量化预览数据

系统必须（MUST）为点云产物生成轻量化预览数据（默认目标不超过 100 万点，可配置）并缓存在会话内；轻量化不得改变任何计算任务使用的全量数据与结果。

#### Scenario: 生成预览

- **WHEN** 任务产生点云产物
- **THEN** 该产物可被预览，且展示点数不超过配置上限

#### Scenario: 不影响计算

- **GIVEN** 某产物已生成轻量化预览
- **WHEN** 以同一产物运行后续计算
- **THEN** 计算结果与不使用预览时一致（计算始终使用全量数据）

### Requirement: 交互查看

浏览器中必须（MUST）支持鼠标交互查看点云（旋转、缩放、平移），交互语义与原演示一致。

#### Scenario: 旋转与缩放

- **WHEN** 用户在预览区拖动鼠标或滚动滚轮
- **THEN** 视角旋转或缩放正常响应

### Requirement: 配色语义

预览配色必须（MUST）与原演示一致：单点云按指定颜色显示；双点云分别以红色与蓝色显示；偏差结果按数值映射色带显示。

#### Scenario: 双点云预览

- **WHEN** 同时预览待配准点云与固定点云
- **THEN** 两者分别以红色与蓝色显示

#### Scenario: 偏差色带

- **WHEN** 预览偏差计算结果
- **THEN** 颜色与偏差数值对应，且剔除后置零语义与基线一致

### Requirement: 预览失败边界

预览生成失败必须（MUST）显式提示；预览不可用不得阻止产物下载或后续计算使用。

#### Scenario: 预览失败

- **GIVEN** 某产物的预览生成失败
- **WHEN** 用户查看该产物
- **THEN** 显示失败原因，且下载与后续计算不受影响
