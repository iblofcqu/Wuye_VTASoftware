# Spec Delta

## MODIFIED Requirements

### Requirement: 统计与直方图

系统必须（MUST）展示与原演示一致的统计指标（检测点数、剔除后最大值、最大值、平均值）与偏差直方图，并支持悬停查看区间信息。浏览器端展示的直方图必须（MUST）具有固定复杂度上限：最多 256 个柱和最多 20 个 x 轴刻度；当原始结果超过上限时，系统必须对连续 bin 做确定性聚合，频率求和，并保留同一次计算的统计口径、剔除线和悬停区间语义。PDF 报告必须继续使用原始报告图，不受浏览器展示上限影响。

#### Scenario: 统计指标

- **WHEN** 评估完成
- **THEN** 四项统计指标与基线一致

#### Scenario: 直方图交互

- **WHEN** 用户将鼠标悬停在直方图上
- **THEN** 显示对应区间或聚合区间的信息

#### Scenario: 大数据量浏览器展示

- **GIVEN** 偏差结果生成的原始直方图超过 256 个柱
- **WHEN** 页面展示该直方图
- **THEN** 浏览器侧 figure 的柱数不超过 256，x 轴刻度不超过 20，且页面仍显示同一组统计指标

#### Scenario: 小结果或空结果

- **GIVEN** 偏差结果的直方图柱数不超过 256
- **WHEN** 页面展示该直方图
- **THEN** 页面不因展示上限而改变原有结果或交互语义

#### Scenario: PDF 报告不受展示上限影响

- **GIVEN** 同一次质量评估同时生成了原始报告图和受限的浏览器展示图
- **WHEN** 用户下载 PDF 报告
- **THEN** PDF 仍使用原始报告图，报告中的统计数字与页面统计指标一致
