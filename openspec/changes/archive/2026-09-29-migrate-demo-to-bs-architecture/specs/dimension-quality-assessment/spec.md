# Spec Delta

## Purpose

定义尺寸质量评估的行为：从已配准的扫描点云与 BIM 点云计算偏差、统计指标与直方图，并生成与原演示一致的 PDF 报告。

## ADDED Requirements

### Requirement: 前置确认

用户必须（MUST）完成与原演示一致的四个前置确认（离散点云、下采样（可忽略）、单位一致、已完成匹配）后，系统才允许进入参数输入与计算。

#### Scenario: 确认未完成

- **GIVEN** 四个确认项未全部勾选
- **WHEN** 用户查看评估页面
- **THEN** 不开放参数输入与计算入口

#### Scenario: 确认完成

- **WHEN** 四个确认项全部勾选
- **THEN** 开放参数输入

### Requirement: 输入与参数

系统必须（MUST）允许选择扫描点云与 BIM 点云（会话产物或上传），并提供与原演示一致的点云单位、偏差计算方法（Point2Point、Point2Plane）、平面邻域大小与剔除比例参数。

#### Scenario: 选择输入

- **WHEN** 用户分别选择扫描点云与 BIM 点云
- **THEN** 可继续设置单位、方法、邻域大小与剔除比例

#### Scenario: 方法相关参数

- **GIVEN** 偏差计算方法选择 Point2Plane
- **WHEN** 设置平面邻域大小
- **THEN** 该参数参与计算；选择 Point2Point 时该参数不生效（与原演示一致）

### Requirement: 偏差计算

偏差计算链路（体素下采样、环境点云剔除、缺失点云剔除、逐点偏差）与结果必须（MUST）与原演示一致，包括已知边界行为（如平面邻域不足时的既有处理）。

#### Scenario: 两种计算方法

- **WHEN** 分别以 Point2Point 与 Point2Plane 完成计算
- **THEN** 偏差数组与基线一致

#### Scenario: 已知边界行为

- **GIVEN** 输入触发原演示中的已知边界情况
- **WHEN** 计算完成
- **THEN** 行为与基线一致（不修复、不改变）

### Requirement: 统计与直方图

系统必须（MUST）展示与原演示一致的统计指标（检测点数、剔除后最大值、最大值、平均值）与偏差直方图，并支持悬停查看区间信息。

#### Scenario: 统计指标

- **WHEN** 评估完成
- **THEN** 四项统计指标与基线一致

#### Scenario: 直方图交互

- **WHEN** 用户将鼠标悬停在直方图上
- **THEN** 显示对应区间的信息

### Requirement: PDF 报告

系统必须（MUST）生成与原演示命名规则与版式一致的 PDF 报告（点云名 + 几何质量评估报告 + 日期），并允许通过浏览器下载。

#### Scenario: 报告生成

- **WHEN** 评估完成
- **THEN** 生成 PDF 报告且文件名符合命名规则

#### Scenario: 报告内容

- **WHEN** 查看生成的报告
- **THEN** 版式、图片与数字与同一次计算结果一致，并与原演示一致

### Requirement: 结果一致性

页面统计、直方图与 PDF 报告中的数字与图片必须（MUST）来自同一次计算，不得出现口径不一致。

#### Scenario: 同源一致

- **WHEN** 一次评估完成
- **THEN** 页面指标与报告中对应数值一致
