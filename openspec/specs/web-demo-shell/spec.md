# web-demo-shell Specification

## Purpose

定义浏览器端演示外壳的行为：用户通过浏览器跨局域网访问系统，使用与原演示一致的页面结构、导航与说明书内容，且所有文件交互都发生在浏览器中，不再接触服务器文件系统。

## Requirements

### Requirement: 首页与导航结构

系统必须（MUST）提供与原演示一致的首页与导航：首页展示品牌图与软件标题；导航包含"点云预处理"（说明书、网格离散、尺寸缩放、下采样、配准）与"尺寸质量评估"。

#### Scenario: 打开首页

- **WHEN** 用户在浏览器打开服务地址
- **THEN** 展示与原演示一致的品牌图片与标题（三维扫描分析系统 / DeviScan-3D）

#### Scenario: 切换功能页面

- **WHEN** 用户点击侧边导航中的任一功能
- **THEN** 进入对应功能页面，且可继续切换到其他功能或返回首页

#### Scenario: 配准子功能

- **WHEN** 用户在"点云预处理"中选择"配准"
- **THEN** 可选择"粗配准"与"精配准"两种方式

### Requirement: 模块说明书

每个功能模块必须（MUST）提供"说明书"入口，其内容与原演示对应模块的说明文字一致。

#### Scenario: 查看说明书

- **WHEN** 用户选择某模块的"说明书"
- **THEN** 展示该模块的算法简介、输入参数与使用说明（与原演示一致）

### Requirement: 无登录访问

系统必须（MUST）支持跨局域网的无登录访问：任意浏览器打开服务地址即可使用全部功能。

#### Scenario: 首次访问

- **WHEN** 用户首次打开服务地址
- **THEN** 无需任何登录或凭据即可进入并使用系统

### Requirement: 无服务器文件系统交互

页面必须（MUST）不出现服务器文件系统相关交互（服务器端文件选择对话框、"打开输出文件夹"、服务器路径展示）；文件的输入与输出必须通过浏览器上传与下载完成。

#### Scenario: 选择输入文件

- **WHEN** 用户在任一工具页面需要选择输入文件
- **THEN** 页面仅提供"上传本机文件"或"选择会话产物"两种入口，不弹出服务器端对话框

#### Scenario: 获取输出结果

- **WHEN** 任务产生结果
- **THEN** 页面提供下载入口，不提供任何"打开文件夹"操作

### Requirement: 会话清空入口与结果反馈

系统必须（MUST）在左侧导航栏最底部提供“清空会话文件”入口。入口必须只触发当前会话的清空流程；执行期间必须阻止重复提交，并在成功或失败后给出明确反馈，不得暴露服务器路径或提供打开文件夹操作。

#### Scenario: 显示底部清空入口

- **GIVEN** 用户已打开任意页面
- **WHEN** 用户查看左侧导航栏
- **THEN** 清空按钮显示在导航栏最底部，并与现有菜单项保持视觉区分

#### Scenario: 确认后清空成功

- **GIVEN** 当前会话没有未完成任务或上传
- **WHEN** 用户点击清空按钮并确认操作
- **THEN** 页面启动 SSE 清空流程，成功后弹出“删除成功”提示，并刷新会话快照使产物、任务和上传列表为空

#### Scenario: 取消确认

- **GIVEN** 用户点击清空按钮
- **WHEN** 用户在确认弹窗中选择取消
- **THEN** 页面不发起清空请求，也不改变当前会话内容

#### Scenario: 清空进行中禁止重复提交

- **GIVEN** 清空流程已经启动
- **WHEN** SSE 尚未返回成功或失败结果
- **THEN** 清空按钮显示加载或禁用状态，用户无法再次发起清空请求

#### Scenario: 清空失败

- **GIVEN** 后端返回冲突、SSE `error` 事件或网络/流解析错误
- **WHEN** 页面收到失败结果
- **THEN** 页面必须显示具体失败原因，不得显示删除成功，并恢复清空按钮以便用户重试
