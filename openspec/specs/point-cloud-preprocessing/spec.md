# point-cloud-preprocessing Specification

## Purpose

定义点云预处理各工具的行为：网格离散、尺寸缩放、下采样、FPFH 粗配准与 ICP 精配准的输入、输出、命名与流程衔接必须与原演示严格一致。

## Requirements

### Requirement: 网格离散

用户提供网格文件与点云间距后，系统必须（MUST）输出离散点云；输出文件命名（网格名 + `.xyz`）、格式与数值结果必须与原演示一致。

#### Scenario: 离散成功

- **GIVEN** 已上传受支持的网格文件并设置合法的点云间距
- **WHEN** 执行网格离散
- **THEN** 产出"网格名.xyz"，其点数与坐标与基线一致

#### Scenario: 非法点间距

- **GIVEN** 点云间距为空或无法解析为数值
- **WHEN** 用户提交网格离散
- **THEN** 任务失败并显式提示，不执行离散

### Requirement: 尺寸缩放

系统必须（MUST）提供与原演示一致的单位换算（m/dm/cm/mm 系数），输出点云命名与数值结果与原演示一致。

#### Scenario: 单位换算

- **GIVEN** 一个点云产物与源/目标单位
- **WHEN** 执行尺寸缩放
- **THEN** 坐标按原演示系数换算，输出与基线一致

### Requirement: 下采样

系统必须（MUST）提供体素下采样与均匀下采样，参数语义、默认值与输出结果必须与原演示一致。

#### Scenario: 体素下采样

- **GIVEN** 一个点云产物与合法体素大小
- **WHEN** 执行体素下采样
- **THEN** 输出点云与基线一致

#### Scenario: 均匀下采样

- **GIVEN** 一个点云产物与合法均匀采样参数
- **WHEN** 执行均匀下采样
- **THEN** 输出点云与基线一致

### Requirement: FPFH 粗配准

用户提供待配准点云、固定点云与体素大小时，系统必须（MUST）执行 FPFH 粗配准，输出命名"待配准点云名 + `_FPFH.xyz`"，坐标变换与结果与原演示一致。

#### Scenario: 粗配准成功

- **GIVEN** 两个点云产物与合法的体素大小
- **WHEN** 执行粗配准
- **THEN** 产出"_FPFH.xyz"且结果与基线一致

#### Scenario: 体素大小非法

- **GIVEN** 体素大小为空或非正数
- **WHEN** 用户提交粗配准
- **THEN** 任务失败并显式提示

### Requirement: ICP 精配准

系统必须（MUST）支持连续三次 ICP 精配准（默认阈值 0.05、0.03、0.005），输出命名"待配准点云名 + `_ICP.xyz`"，结果与原演示一致。

#### Scenario: 精配准成功

- **GIVEN** 两个点云产物与三个合法阈值
- **WHEN** 执行精配准
- **THEN** 产出"_ICP.xyz"且结果与基线一致

### Requirement: 粗配准到精配准的交接

粗配准成功后，其产物必须（MUST）可作为精配准的默认输入，无需用户重新上传或重新选择；用户也可以改为其他会话产物或新上传文件。

#### Scenario: 默认交接

- **GIVEN** 当前会话刚完成一次粗配准
- **WHEN** 用户进入精配准
- **THEN** 移动点云默认选中该粗配准产物

#### Scenario: 替换输入

- **WHEN** 用户改选其他产物或上传新文件
- **THEN** 精配准使用用户选择的输入

### Requirement: 严格保持原样

同一输入下，各预处理工具的输出必须（MUST）与 base_software 基线逐点一致（含既有缺陷与命名规则）；搬迁过程不得引入任何行为修复。

#### Scenario: 与基线对比

- **GIVEN** 同一组样例输入
- **WHEN** 基线实现与新实现分别执行同一工具
- **THEN** 输出数值与格式一致（容差为 0 或已声明的对比容差）
