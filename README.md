# Wuye_VTASoftware
五冶预拼拼装软件项目
25年为五冶申请的软著，如今需要嵌入他们的系统
界面通过Streamlit展示，run运行home_page.py，除home_page外，只包含pages文件夹中的点云预处理和尺寸质量评估界面
完整运行需在电脑中安装TeXstudio(用于生成PDF报告)以及Google Chrome(提供安装包)
压缩包DeviScan3D为打包的软件，包含了所有的包，解压该文件运行.exe可直接运行
五冶当前本身有一个系统，他们自己在系统加了个按钮，链接到.exe文件，但部署在服务器上
问题：
（1）该软件解压在他们的服务器上
（2）通过局域网进入软件，但Demo编写的时候，上传文件功能只链接了本地文件（即只可浏览部署电脑上的文件）
（3）通过局域网访问的时候，界面浏览文件框看不到文件目录
针对上述问题，五冶想看看能不能重新打包，东声让软件工程师评估一下打包工作量
